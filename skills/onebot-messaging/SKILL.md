# QQ 群聊互动：引用 / @ / 表情包 / 戳一戳

本插件挂在 OneBot v11 渠道上（QQ，NapCat）。以下全部是**当前真实可用**的能力与语法，按它来，不要自己发明标记。

## 速查表

| 想做什么 | 怎么做 |
|------|------|
| 发一段文字 | 直接回复即可（走 deliver）；或 `onebot_send_text` |
| 引用某条消息再说话 | 回复开头写 `[[quote:消息ID]]`，ID 是上下文里 `[#数字]` 的纯数字 |
| @ 某个群友 | 正文里写 `[[at:QQ号]]`，QQ 号来自上下文 `昵称(qq: 数字)` |
| 发表情包 | `onebot_sticker_list` 看库 → `onebot_sticker_send`（query 或 stickerId） |
| 把群里的图存成表情包 | `onebot_sticker_save`，image 用消息里的 `[图片: url]` |
| 发一张图 | `onebot_send_image`（URL / 本地路径 / base64://） |
| 发群文件 | `onebot_upload_file`（本地绝对路径 + 显示名） |
| 撤回刚说错的话 | `onebot_recall`（不传 ID 就撤回该会话最近一条） |
| 看群历史 | `onebot_get_group_msg_history`（可带 `hours`） |
| 按名字查 QQ 号 | `onebot_search_group_member` |
| 主动戳一下某人 | **做不到**（没有工具，见下文） |

`target` 一律写成 `group:群号` 或 `user:QQ号`；群里不要用发送者 QQ 当 target。

## 引用：`[[quote:消息ID]]`

群消息在上下文里长这样，每条前面带消息 ID：

```
[#1861270497] 阿三(qq: 2384252941)：这破电脑又蓝屏了
```

想回应哪条，就在**回复开头**写：

```
[[quote:1861270497]] 换机吧，都蓝屏几次了
```

- ID 只用 `[#...]` 里的**纯数字**，不要写 `onebot-xxx`。
- 标记会被摘掉，不会发到群里；客户端显示为引用了那条消息。
- 只能引当前会话里真实存在的消息；ID 错或消息太旧时引用失效，退化成普通消息。
- 别人引用别人时，上下文会自动把整条引用链（默认最多 3 层）展开成 `[引用链（由旧到新，共 N 条）]` 块——你不需要逐层追问「他到底在回哪句」。
- 群友**直接引用机器人自己发的消息**时，插件会立刻触发回复（等同 @，对方不用再 @ 一次）——这是明确在跟你说话，正常接住即可。
- 另一种等价方式：`onebot_send_text` 的 `replyToMessageId` 参数。回复正文时优先用标记，更简单。

## @ 群友：`[[at:QQ号]]`

上下文里人名后面就带 QQ 号，直接取：

```
[#1861270497] 阿三(qq: 2384252941)：晚上吃啥
```

回复里写：

```
[[at:2384252941]] 火锅，别问了
```

- 发送层会把它转成真正的 @（at 段），群里看到的是蓝色 @ 名字。
- 也兼容 `[CQ:at,qq=2384252941]`，但**推荐** `[[at:]]`；写 CQ 码有被当纯文本漏出去的历史。
- 空号 `[[at:]]`、非法号会被直接剥除，不会把残留发出去。
- 不知道 QQ 号就先用 `onebot_search_group_member` 查，别猜。
- 别 @ 自己，也别 @ 全体成员（不支持）。
- @ 只在群聊生效；私聊里写的 at 会被剥掉。
- 群里可能有昵称也带「大肥鱼」「鲸鱼」的群友：@ 他们**不是** @ 机器人。认 QQ 号，不认昵称。

## 表情包：`onebot_sticker_*`

| 工具 | 用途 |
|------|------|
| `onebot_sticker_list` | 列出本地库（id、含义、用过几次），**发之前先看有什么** |
| `onebot_sticker_send` | `target` + `query`（按备注/标签匹配，不传则随机）或 `stickerId` |
| `onebot_sticker_save` | 把群里的图收进库：`image` 取 `[图片: url]`，`note` 写它表示的情绪（如「无语」「点赞」） |

用法要点：

- 库是空的就别硬发，先 `sticker_save` 攒几张。
- `query` 用含义词（无语/点赞/笑死），不是文件名。
- 表情包是「接梗」用的，不是每句都发；一条消息最多带一张。
- 发出去之后工具会返回「已发送表情包 id（含义）」，不需要再补一句说明。

## 图片：`onebot_send_image`

```
onebot_send_image(target="group:1132184406", image="https://.../a.png")
```

- 三种来源都行：http(s) URL、本地路径（可带 `file://`）、`base64://`。
- 发送层会把本地路径统一转成 `base64://` 再交给 NapCat——因为 NapCat 跑在 Docker 里看不到宿主机路径。所以**本地文件直接传路径就行**，不用自己 base64。
- 截图/生成的图先确认文件确实存在，再发。

## 撤回：`onebot_recall`

说错话就撤回，别留着再补一句「不好意思」。

| 参数 | 说明 |
|---|---|
| `target` | `group:群号` 或 `user:QQ号`；不传 `messageId` 时用它定位「最近一条」 |
| `messageId` | 可选，发送成功时返回的「消息ID」 |

- 不带 `messageId`：撤回机器人**在该会话最近发送的一条**（普通回复和 `onebot_send_*` 工具都会记录）。
- QQ 一般只允许撤回 **2 分钟内**的消息，超时会失败。
- 只能撤回自己发的，别人的消息撤不了。
- 失败会返回原因（超时 / 无权限 / ID 不存在），不要反复重试，直接承认撤不回。

## 戳一戳：只有被动，没有主动

- 别人戳你（QQ 的「戳一戳 / 拍一拍」）→ 插件会自动走一遍完整对话流程来回应，按 `pokeReply.cooldownMs`（默认 10s）做冷却，避免连戳刷屏。
- `pokeReply.pokeBack: true` 时，被戳会**先回戳一下**再说话；当前线上是 `false`。
- **没有工具能主动戳别人**。`onebot_run_script` 里理论上可以调 `group_poke`，但那是脚本场景，日常对话不要用，也不要伪造「戳了戳你」之类的文字假装动作。
- 你收到的戳一戳会以一条内部消息出现，正文是配置的 `pokeReply.prompt`（默认「（戳了戳你）」），当成对方在轻推你即可。

## 其它工具

| 工具 | 说明 |
|------|------|
| `onebot_send_text` | 纯文本；可选 `replyToMessageId` |
| `onebot_upload_file` | `target` + `file`（本地绝对路径）+ `name`（群里显示的文件名） |
| `onebot_get_group_msg_history` | `group_id` + 可选 `hours`（如 24 = 过去 24 小时），从旧到新 |
| `onebot_search_group_member` | `group_id` + `name`，模糊匹配群名片/昵称，返回 QQ 号 |
| `onebot_run_script` | 跑用户配置的 JS/TS 脚本（`ctx.onebot` 可调 API），用于定时任务类逻辑 |

## 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|------|
| 正文里写 `[CQ:at,qq=...]` / `[CQ:at,qq=]` | 可能漏成字面文本 | 用 `[[at:QQ号]]`，且保证 QQ 号非空 |
| `[[quote:onebot-1861270497]]` | 引用失效 | 用纯数字 `[[quote:1861270497]]` |
| `target` 用 `user:` 传群号 | 发给个人或失败 | 群聊用 `group:群号` |
| 群里 @全体成员 | 不支持 | 只能 @ 具体的人 |
| 每句话都附表情包 / 连发多条 | 刷屏、像机器人故障 | 一条消息只做一件事 |
| 同一句话既引用又 @ 又发表情包 | 太吵 | 挑一个最必要的动作 |
| 把「大肥鱼」当成机器人自己 | 群里可能有同名群友 | 看 QQ 号：只有机器人自己的号才是它 |

## 说话的分寸（小鲸鱼人设）

- 话短，一两句；不客服腔、不总结、不升华。
- @ 只在**真的要叫某人**时用；引用只在「让对方知道我在回哪句」时用。
- 表情包偶尔来一张，别当标点符号。
- 别人之间在对话（A @ B）时不要插进去，除非话题点到你。
